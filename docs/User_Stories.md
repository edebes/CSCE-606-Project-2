As an instructor, so that I can control exactly what we practice in class, I want to be able to make my own custom question sets.
As an instructor, so that I can run in-class problems that engage every student, I want to be able to host a session of a questions set.
As an instructor, so that I can provide instant feedback to each of my students, I want to be able to pre-program feedback for common wrong answers.
As an instructor, so that I can provide additional feedback to each of my students, I want to be able to give live feedback during a session.
As a student, so that I can participate and receive feedback, I want to be able to join an in-class session.
As a TA, so that I can help provide live-feedback, I want to be able to join an in-class session as a TA role.
As a student, so that I am able to join the right session, I want to see a clear error when I join the incorrect session.
As an instructor, so that I can see where the class struggled to understand, I want to view the summary of answers and common mistakes when I end a session.
As a student, so that I can correct my mistakes in the same session, I want to resubmit my answer after receiving feedback on a wrong one.
